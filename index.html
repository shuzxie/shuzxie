Reference
API
Upload file
Multipart form. Ulangi field file untuk upload sampai 5 file sekaligus.
POST /api/upload-file 
# 1 file
curl -X POST __ORIGIN__/api/upload-file \
  -F "file=@/path/to/file.pdf"

# banyak file (maks 5)
curl -X POST __ORIGIN__/api/upload-file \
  -F "file=@a.jpg" \
  -F "file=@b.png" \
  -F "file=@c.pdf"
Upload via URL
Server narik file dari URL, lalu diteruskan ke CDN. Pakai url atau urls (array, maks 5).
POST /api/upload-url 
# 1 url
curl -X POST __ORIGIN__/api/upload-url \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/file.pdf"}'

# banyak url
curl -X POST __ORIGIN__/api/upload-url \
  -H "Content-Type: application/json" \
  -d '{"urls": ["https://example.com/a.jpg", "https://example.com/b.png"]}'
Response
